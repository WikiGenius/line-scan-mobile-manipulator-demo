# Related projects

This repository is a planned line-scan application within the broader [perception-aware motion planning portfolio](https://github.com/WikiGenius). It has no complete runnable demo.

| Project | Potential contribution |
| --- | --- |
| [WMM planning and tracking](https://github.com/WikiGenius/wmm-planning-and-tracking) | Coordinated motion and feedback tracking |
| [MoveIt grasping](https://github.com/WikiGenius/ros2-moveit-grasping-demo) | Robot execution patterns |
| [Screw Theory Toolkit](https://github.com/WikiGenius/RoboticScrewTheoryToolkit) | Kinematic feasibility |
| [Husky image capture](https://github.com/WikiGenius/husky-gazebo-image-capture) | Sensor acquisition and logging |
| [GTSAM SLAM Vision](https://github.com/WikiGenius/GTSAM_SLAM_VISION) | Pose-estimation experiments |
| [NeRF Lab](https://github.com/WikiGenius/nerf-lab) | Scene representation and ray geometry |
| [Research reading map](https://github.com/WikiGenius/research-reading-map) | Reading questions and note templates |

These are conceptual connections. None of these projects is integrated into this scaffold.

The [ROS2 scaffold](https://github.com/WikiGenius/ros2-mobile-robotics-labs) and [control index](https://github.com/WikiGenius/robotics-control-learning-labs) provide navigation to separate implementations.
